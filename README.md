# 🎮 term2048

2048 playable directly in the terminal.

Small Python implementation focused on **clean logic, simple structure, and testable mechanics**.

---

## 📦 What's inside

- **🧠 Game logic**  
  Core 2048 mechanics implemented in Python.

- **📋 Board system**  
  Handles tile movement, merging rules, and board state.

- **🧪 Tests**  
  Pytest suite validating board behavior.

- **📜 Scripts**  
  Small helper scripts for development.

---

## 🧪 Run tests

```bash
pytest
```

---

## 🎯 Goals

- readable Python code  
- simple architecture  
- easy testing  
- minimal dependencies
